# MAP project handoff checklist

Due in finals week. Your project is part of MAP only when every box is checked.

## Files (SharePoint: `Projects/<your project id>/`)

- [ ] `README.md` from `templates/README_dataset.md`, filled in
- [ ] `01_Report/` — final report as PDF, checked with an accessibility checker
- [ ] `02_Data/` — geodatabase **plus** open formats (GeoJSON or CSV), with a data dictionary
- [ ] `03_Code/` — scripts, or a link to your GitHub repo
- [ ] `04_Media/` — photos, audio, scans, with file names that say what they are
- [ ] `05_Presentation/` — final slides

## ArcGIS Online

- [ ] Every story map, web map, dashboard, form and layer is shared to the **MAP Working** group
- [ ] Each item has a summary, tags (`Mapping Accessibility` plus your theme) and the CC BY 4.0 license in its terms of use
- [ ] Every map has a text alternative (a text version of the story map, or a description of what the map shows)
- [ ] You have agreed to transfer ownership of the items to the MAP coordinator

## Code

- [ ] Code is in a repo in the WWU-Mapping-Accessibility GitHub organization, with a README that explains how to run it

## Zotero

- [ ] At least 5 sources in your project's Zotero collection, each with a one-line note on why it mattered

## Registry

- [ ] Pull request adding `projects/<your project id>.yml`, made from `templates/project.yml`
- [ ] Summary of about 100 plain-language words, with your most important finding and its number
- [ ] One image with alt text
- [ ] Everyone on the team has said whether their name may appear publicly (`names_public`)
